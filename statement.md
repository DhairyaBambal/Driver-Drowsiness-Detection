# Project Statement

## Problem Statement

Driver drowsiness is a major cause of road accidents. Drivers may become fatigued during long journeys or while driving at night. This project provides a real-time computer vision system that monitors the driver's eyes and detects prolonged eye closure.

## Scope

The system uses a webcam to monitor the driver's eyes and calculate the Eye Aspect Ratio (EAR). If prolonged eye closure is detected, the system identifies drowsiness and activates an emergency alarm.

## Target Users

- Drivers
- Transport companies
- Fleet management systems
- Road safety applications

## High-Level Features

- Real-time webcam monitoring
- Eye landmark detection
- Eye Aspect Ratio calculation
- Drowsiness detection
- Emergency audio alert
- Drowsiness event tracking
- Monitoring statistics
- Streamlit-based interface
